# Secrets & Schemes — 64-Card Candidate Pool

**Release target:** Imprompt v0.13.0  
**Selected:** 48  
**Held:** 8  
**Rejected:** 8  

The pool intentionally exceeds the 48 playable slots so selection can reject overlap, hidden-information violations, fixed genre premises, ethically weak manipulation, and ideas that belong more naturally in later packs.
