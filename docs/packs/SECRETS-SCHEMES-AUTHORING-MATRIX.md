# Secrets & Schemes — 48-Slot Authoring Matrix

**Pack ID:** `secrets-schemes`  
**Reserved IDs:** S121–S144 and D121–D144  
**Target release:** Imprompt v0.13.0  
**Status:** Complete selected matrix; live playtest pending

Every formal Card Bible subtheme receives exactly one selected Pack 6 card. This preserves the ten-pack architecture while interpreting each slot through concealment, investigation, recruitment, misdirection, confession, or plans under pressure.
