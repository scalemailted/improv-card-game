## Before deploying over an older version

Replace project files, close existing game tabs, and reopen the same site/port. Keep the same origin to reuse model files. Do not clear all site data as a cache-refresh method. The new prompt uses a separate generated-text cache and removes the old generated cache only.

Test a real single-card request, a real pair and Another angle. Inspect any failed request under Generation details before concluding that the displayed built-in fallback was generated by AI. Run the optional real-model check page and inspect whether each output actually expresses the requested cards.
