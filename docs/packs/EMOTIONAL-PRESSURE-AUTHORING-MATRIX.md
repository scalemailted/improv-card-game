# Emotional Pressure — 48-Slot Authoring Matrix

**Pack:** Emotional Pressure  
**Reserved IDs:** S97–S120 and D97–D120  
**Target release:** Imprompt v0.12.0  
**Status:** Editorial selection complete; live playtest pending

Each row fills one required Card Bible subtheme. The pack contributes exactly one card to every formal subtheme while interpreting each through insecurity, validation, resentment, hope, grief, shame, or emotional uncertainty.
