# Imprompt Example Scene Contract

A holds the requested card for a single-card example, and both selected cards for a combination. B is an illustrative scene partner. Their dialogue demonstrates one possible response, not a requirement imposed on a real player.

The dataset covers all 57,600 private Stance–Drive combinations and all 480 single cards. Single scenes use A–B–A; pair scenes use A–B–A or A–B–A–B–A. Each scene must show specific behavior, a meaningful reply and a responsive follow-through. No abstract coaching appears in the nudge.

For authoring, versioning, provenance and known limitations see OFFLINE-ACT-IT-OUT-LIBRARY.md. The runtime module hint-bible.js now controls only example availability policies. The former template coaching engines and local-inference modules are not shipped.
